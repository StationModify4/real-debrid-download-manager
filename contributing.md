## ⚙️ How It Works

<div align="center">

| Layer | Responsibility | Tech |
|:---|:---|:---|
| 🖥️ **Frontend UI** | Native windows, dark themes, drag-and-drop queue | `Wails` / `React` |
| ⚡ **Backend Core** | Handles API authentication and link conversion | `Go (Golang)` |
| 📥 **Downloader** | Multi-threaded file downloading and chunk management | `Aria2` |
| 🗄️ **Storage** | Encrypted local storage for API keys and history | `SQLite` |

</div>

The application uses the Wails framework to bind a Go backend to a beautiful React frontend. This results in a lightweight, ultra-fast desktop app that doesn't eat up your RAM like Electron-based apps do.

</details>

<details>
<summary><b>Do I need a Real-Debrid account to use this?</b></summary>

Yes. This app acts as a premium manager for your existing Real-Debrid subscription. It does not generate premium access out of thin air.
</details>

<details>
<summary><b>Does it support Windows and Mac?</b></summary>

Absolutely. The app is built with Go and compiles to native binaries for Windows 10/11, macOS (Intel and Apple Silicon), and Linux.
</details>

<details>
<summary><b>How secure is my API key?</b></summary>

Your API key is stored locally on your machine using AES-256 encryption. It is never sent to our servers (because we don't have any!). Everything happens locally.
</details>

Open an issue on the GitHub repository. Include your OS, the version of the app, and the specific filehost link that failed.
